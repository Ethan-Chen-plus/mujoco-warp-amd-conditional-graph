The MuJoCo-Warp source requires MuJoCo 3.8.0 or newer. Do not reuse an older
JAX environment that contains MuJoCo 3.4.0 for this benchmark.

## Runtime variables

```bash
export MUJOCO_GL=egl
export MJW_HIP_SINGLE_STREAM=1
export WP_HIP_GRAPH_ENABLE=0
export PYTHONPATH="$ROOT/upstream/warp:$ROOT/upstream/mujoco_warp"
export HIP_CLR_LIB=/path/to/patched/libamdhip64.so
export LD_LIBRARY_PATH="$(dirname "$HIP_CLR_LIB"):$ROOT/upstream/warp/warp/bin:/opt/rocm/lib:/opt/rocm/lib64"
```

The source-built Warp package must produce `upstream/warp/warp/bin/warp.so`
before the full benchmark is run. The public repository intentionally does not
ship that machine-specific binary.

## Native conditional runtime

The native path requires the paired patches in
`patches/hip-clr-conditional.diff` and `patches/hip-sdk-conditional.diff`.
Apply and build them with `scripts/build_patched_hip_runtime.sh`, then rebuild
Warp with `HIP_GRAPH_CONDITIONAL_EXT=1` and the patched HIP headers before
running:

```bash
export WP_HIP_CONDITIONAL_NATIVE=1
export WP_HIP_CONDITIONAL_EMULATION=0
```

The library and extension hashes used by the primary result are stored in
`results/mjwarp_native_conditional_amd395/summary.json`.
